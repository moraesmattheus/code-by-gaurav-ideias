# CodeByGaurav • Catálogo de Efeitos & Ideias UI para Novos Sites

Acervo completo de **35 componentes frontend interativos**, extraídos diretamente dos vídeos, tutoriais e projetos virais do perfil **CodeByGaurav** ([Facebook](https://www.facebook.com/CodeByGaurav) / Gaurav Sisodiya) somados às tendências modernas de UI Design (Glassmorphism, Neon Glow e 3D).

Todos os códigos utilizam **HTML5, CSS3 e JavaScript puro (Vanilla)**, sem dependências de frameworks pesados, com foco em alta performance, carregamento instantâneo e facilidade de adaptação para qualquer novo site ou landing page.

---

## Como Abrir e Testar

O projeto possui um **UI Component Studio (`index.html`)** profissional com:
- **Modo Studio:** Palco amplo em alta resolução com simulador responsivo para **Desktop (100%)**, **Tablet (768px)** e **Mobile (390px)**;
- **Modo Galeria:** Grade com cartões interativos de todos os componentes;
- **Busca Instantânea:** Filtre qualquer efeito em tempo real por nome ou funcionalidade;
- **Abas de Código:** Copie com 1 clique o **HTML5**, **CSS3** ou **JavaScript** pronto para produção;
- **Guia de Integração:** Dicas práticas e gatilhos mentais para usar cada componente em novos sites.

Acesse diretamente pelo navegador no servidor local ativo:
👉 **[http://localhost:3333](http://localhost:3333)**
