# CodeByGaurav • Catálogo de Efeitos & Ideias UI para Novos Sites

Acervo completo de **25 componentes frontend interativos**, extraídos, reconstruídos e documentados a partir de todos os vídeos, tutoriais e projetos do perfil **CodeByGaurav** ([Facebook](https://www.facebook.com/CodeByGaurav) / Gaurav Sisodiya).

Todos os códigos utilizam **HTML5, CSS3 e JavaScript puro (Vanilla)**, sem dependências de frameworks pesados, com foco em alta performance, carregamento instantâneo e facilidade de adaptação para qualquer novo site ou landing page.

---

## Como Abrir e Testar

O projeto possui um **Hub Interativo Central (`index.html`)** com:
- Preview ao vivo em tempo real de cada componente;
- Busca instantânea por palavras-chave (ex.: `login`, `neon`, `relogio`, `otp`, `navbar`);
- Filtros por categoria (Autenticação, Navegação, Botões, Relógios, Utilitários);
- Botões de cópia direta com 1 clique (HTML, CSS e JS);
- Botão para abrir o componente em tela cheia (`componentes/XX-nome/index.html`).

Para abrir o Hub no navegador:
1. Navegue até a pasta: `C:\Users\matth\Documents\Github\sites\code-by-gaurav-ideias`
2. Dê dois cliques em `index.html` (ou abra via Live Server / navegador de sua preferência).

- `style.css`: Estilização modular com seções comentadas (reset, container, efeitos, animações, responsividade).
- `script.js` (quando aplicável): Lógica JavaScript comentada passo a passo.
